# AirPods Battery Widget

A macOS desktop widget that displays real-time battery levels for your AirPods.

## Features

- Shows battery levels for left AirPod, right AirPod, and charging case
- Automatic light/dark theme based on system appearance
- Color-coded battery indicators (green, yellow, red)
- Respects reduced motion preferences
- Refreshes every 30 seconds

## Requirements

- macOS with Bluetooth enabled
- AirPods connected and case opened to populate data

## Usage

Place the widget in your Übersicht widgets directory. The widget automatically reads Bluetooth data via `system_profiler SPBluetoothDataType`.

## Dimensions

- Width: 200px
- Height: 175px
